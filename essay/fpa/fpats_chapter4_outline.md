# 第四章 基于FPA-TS的移动边缘计算多目标任务卸载优化

## 章节概述
本章在第三章TLBO-HHO算法的基础上,针对实际部署中用户体验质量(QoE)和资源分配公平性需求,提出一种基于花粉授粉算法与禁忌搜索(FPA-TS)混合的五目标优化方法,综合优化能耗、时延、信息年龄(AoI)、QoE和公平性五个维度,以满足多样化边缘计算场景的需求。

### 4.3.4 能耗模型

**内容要点:**
- **本地执行能耗** (公式+1段)
```
E_local = κ · C_task · f_d²
其中:κ为能耗系数, C_task为任务计算量, f_d为设备频率
```

- **卸载能耗** (公式+2段)
  - 传输能耗:E_trans = P_tx · t_trans
  - 边缘/云执行能耗:E_exec = κ · C_task · f_server²
  - 总能耗:E_total = E_trans + E_exec

- **[可选]电池状态建模** (公式+1段)
```
B(t+1) = B(t) - E_consumed(t)
```

### 4.3.5 时延模型

**内容要点:**
- **本地执行时延** (公式+1段)
```
T_local = C_task / f_d
```

- **卸载时延** (公式+2段)
  - 传输时延:T_trans = Data_size / R_trans
  - 传输速率:R_trans = B · log₂(1 + SNR)
  - 排队时延:T_queue (考虑服务器负载)
  - 计算时延:T_comp = C_task / f_server
  - 总时延:T_total = T_trans + T_queue + T_comp + T_backhaul

- **时延约束** (公式+1段)
```
T_total ≤ T_max (deadline constraint)
```

### 4.3.7 QoE模型

**内容要点:**
- **QoE定义与意义** (1-2段)
  - QoE是用户满意度的综合度量
  - 考虑时延满足度、能耗接受度、任务完成率

- **QoE数学模型** (公式+2-3段)
```
QoE_i = α · (1 - T_i/T_max,i) + β · (1 - E_i/E_budget,i) + γ · (1 - AoI_i/AoI_max,i)

其中:
α + β + γ = 1 (归一化权重)
α = 0.4 (时延权重)
β = 0.3 (能耗权重)
γ = 0.3 (新鲜度权重)
```

- **电池感知自适应权重** (公式+1-2段)
```
φ_i(t) = Battery_level_i / 100
Cost_i = φ_i · Delay_i + (1-φ_i) · Energy_i

当电量高时(φ≈1):优先时延最小化
当电量低时(φ≈0):优先能耗最小化
```

- **QoE约束** (公式+1段)
```
QoE_i ≥ QoE_min (最低满意度保证)
```

### 4.3.8 公平性模型

**内容要点:**
- **公平性的重要性** (1段)
  - 多租户环境需要公平分配
  - 避免资源垄断
  - 保证服务质量均衡

- **Jain公平性指数** (公式+2段)
```
Fairness = (Σᵢ QoE_i)² / (N · Σᵢ QoE_i²)

取值范围:[1/N, 1]
Fairness = 1:完全公平(所有用户QoE相等)
Fairness = 1/N:最不公平(一个用户获得全部资源)
```

- **归一化Jain指数** (公式+1段)
```
Fairness_norm = (Fairness - 1/N) / (1 - 1/N)
取值范围:[0, 1],便于与其他目标联合优化
```

- **公平性约束** (公式+1段)
```
Fairness ≥ 0.8 (实际系统可接受阈值)
```

### 4.4.2 花粉授粉算法(FPA)基础

**内容要点:**
- **生物学启发** (1-2段)
  - 花粉授粉的自然现象
  - 全局授粉:风媒、昆虫长距离传播
  - 局部授粉:自花授粉、近距离传播

- **数学建模** (公式+2-3段)

**全局授粉**(探索阶段):
```
x_i^(t+1) = x_i^t + L(λ) · (g* - x_i^t)

其中:
L(λ):Lévy飞行分布,产生长距离跳跃
g*:当前最优解
λ = 1.5(标准Lévy指数)

Lévy飞行步长:
L(λ) ~ s^(-λ), s = (σ_u / |σ_v|^(1/λ))

σ_u ~ N(0, σ_u²), σ_v ~ N(0, 1)
σ_u = {Γ(1+λ)·sin(πλ/2) / [Γ((1+λ)/2)·λ·2^((λ-1)/2)]}^(1/λ)
```

**局部授粉**(利用阶段):
```
x_i^(t+1) = x_i^t + ε · (x_j^t - x_k^t)

其中:
ε ~ U(0,1):均匀分布随机数
x_j^t, x_k^t:随机选择的两个花粉(解)
局部授粉在邻域内探索,类似交叉操作
```

- **切换概率** (公式+1-2段)
```
p ∈ [0,1]:切换概率
if rand() < p: 执行全局授粉
else: 执行局部授粉

标准FPA: p = 0.8(固定值)
本章改进: p动态调整(见4.4.4节)
```

### 4.4.3 禁忌搜索(TS)集成

**内容要点:**
- **禁忌搜索原理** (2-3段)
  - 禁忌表(Tabu List):记录最近访问的解
  - 禁忌期限(Tabu Tenure):解在禁忌表中停留的迭代次数
  - 藐视准则(Aspiration Criterion):允许打破禁忌的条件
  - 短期记忆:避免循环
  - 长期记忆:多样化搜索(可选)

- **禁忌表结构** (1-2段+伪代码)
```
TabuList = []  # 禁忌表
TabuTenure = 15  # 禁忌期限(迭代次数)

结构:
TabuList[i] = {
    'solution': x_i,
    'fitness': f(x_i),
    'remaining_tenure': t
}
```

- **禁忌搜索过程** (公式+2段)
```
邻域生成:N(x) = {x' | x'通过小扰动x得到}
候选解筛选:
  if x' in TabuList and f(x') < f(best_so_far):
     接受x' (藐视准则)
  else if x' not in TabuList:
     接受x'

禁忌表更新:
  插入新解x'
  移除超过tenure的旧解
```

- **与FPA的集成策略** (1-2段)
  - FPA负责全局探索和粗粒度搜索
  - TS负责局部细化和避免重复
  - 每隔N_ts次迭代触发一次TS
  - TS作用于当前最优解的邻域

### 4.4.4 自适应概率机制

**内容要点:**
- **固定概率的局限性** (1段)
  - 标准FPA使用p=0.8固定切换概率
  - 无法根据搜索进度调整探索-利用平衡
  - 早期可能过度利用,后期可能过度探索

- **自适应概率公式** (公式+2-3段)
```
p(t) = 1 / (1 + exp(-k·(D(t) - D_avg)))

其中:
t:当前迭代次数
D(t):种群多样性度量
D_avg:平均多样性阈值
k:调节参数(k=5)

种群多样性计算:
D(t) = (1/N) Σᵢ ||x_i - x_mean||

当D(t) > D_avg: p(t)较大,更多全局授粉(探索)
当D(t) < D_avg: p(t)较小,更多局部授粉(利用)
```

- **优势分析** (1-2段)
  - 自动平衡探索与利用
  - 避免早熟收敛
  - 适应不同阶段的搜索需求

### 4.4.5 解编码与适应度评估

**内容要点:**
- **解的编码方式** (1-2段)
```
Solution = [part1, part2, part3]

part1 (任务分配): [x₁, x₂, ..., x_K]
  x_i ∈ [0, 2.99]:连续值映射到离散{0,1,2}
  x_i = ⌊value⌋ mod 3
  
part2 (CPU分配): [f₁, f₂, ..., f_K]
  f_i ∈ [f_min, f_max]:连续值
  
part3 (带宽分配): [b₁, b₂, ..., b_K]
  b_i ∈ [b_min, b_max]:连续值
```

- **适应度函数** (公式+2-3段)
```
Fitness(X) = w₁·F₁_norm + w₂·F₂_norm + w₃·F₃_norm 
           + w₄·F₄_norm + w₅·F₅_norm + Penalty(X)

归一化:
F_i_norm = (F_i - F_i_min) / (F_i_max - F_i_min)

权重设置:
w₁ = 0.20 (能耗)
w₂ = 0.20 (时延)
w₃ = 0.20 (AoI)
w₄ = 0.20 (QoE)
w₅ = 0.20 (公平性)

惩罚项:
Penalty(X) = Σ penalty_i × (violation_i)²
```

- **约束处理机制** (1-2段)
```
违反约束C4-C8时施加惩罚:
penalty_delay = 10000 × max(0, Delay_i - T_max,i)
penalty_energy = 10000 × max(0, Energy_i - E_budget,i)
penalty_aoi = 10000 × max(0, AoI_i - AoI_max,i)
penalty_qoe = 10000 × max(0, QoE_min - QoE_i)
penalty_fairness = 10000 × max(0, 0.8 - Fairness)
```

### 4.4.6 FPA-TS完整算法流程

**内容要点:**
- **算法伪代码** (算法框图)

**算法4-1 FPA-TS算法**
```
Input: 
  N: 种群大小
  T_max: 最大迭代次数
  TabuTenure: 禁忌期限
  N_ts: TS触发频率
  
Output:
  X_best: 最优解
  F_best: 最优适应度

1: 初始化种群 P = {x₁, x₂, ..., x_N}
2: TabuList ← ∅
3: 评估所有个体适应度,找到当前最优x_best
4: for t = 1 to T_max do
5:     计算种群多样性 D(t)
6:     计算自适应切换概率 p(t)
7:     
8:     // FPA主循环
9:     for i = 1 to N do
10:        if rand() < p(t) then
11:            // 全局授粉(探索)
12:            L ← LevyFlight(λ=1.5)
13:            x_i^new ← x_i + L · (x_best - x_i)
14:        else
15:            // 局部授粉(利用)
16:            随机选择 x_j, x_k (j≠k≠i)
17:            ε ~ U(0,1)
18:            x_i^new ← x_i + ε · (x_j - x_k)
19:        end if
20:        
21:        // 边界处理
22:        x_i^new ← BoundaryCheck(x_i^new)
23:        
24:        // 约束修复
25:        x_i^new ← ConstraintRepair(x_i^new)
26:        
27:        // 评估新解
28:        f_i^new ← Fitness(x_i^new)
29:        
30:        // 贪婪选择
31:        if f_i^new < f_i then
32:            x_i ← x_i^new
33:            f_i ← f_i^new
34:            if f_i < f_best then
35:                x_best ← x_i
36:                f_best ← f_i
37:            end if
38:        end if
39:    end for
40:    
41:    // 禁忌搜索集成
42:    if t mod N_ts == 0 then
43:        // 在最优解邻域执行TS
44:        x_ts ← TabuSearch(x_best, TabuList, TabuTenure)
45:        f_ts ← Fitness(x_ts)
46:        if f_ts < f_best then
47:            x_best ← x_ts
48:            f_best ← f_ts
49:        end if
50:    end if
51:    
52:    // 更新禁忌表
53:    UpdateTabuList(TabuList, x_best, TabuTenure)
54: end for
55: return x_best, f_best
```

- **关键函数说明** (2-3段)

**LevyFlight(λ)**:生成Lévy飞行步长
```
σ_u = {Γ(1+λ)·sin(πλ/2) / [Γ((1+λ)/2)·λ·2^((λ-1)/2)]}^(1/λ)
u ~ N(0, σ_u²)
v ~ N(0, 1)
step = u / |v|^(1/λ)
return step
```

**TabuSearch(x, TabuList, Tenure)**:禁忌搜索过程
```
1. 生成x的邻域 N(x)
2. 筛选候选解:
   - 不在TabuList中
   - 或满足藐视准则(fitness < f_best_ever)
3. 选择最优候选解
4. 更新TabuList
5. 返回最优解
```

**ConstraintRepair(x)**:约束修复
```
1. 检查容量约束C2, C3
2. 若违反,重新分配资源:
   - 按任务优先级排序
   - 优先保证高优先级任务
3. 检查性能约束C4-C8
4. 若违反,调整卸载决策
5. 返回修复后的解
```

### 4.4.7 算法复杂度分析

**内容要点:**
- **时间复杂度** (1-2段+公式)
```
FPA部分:
  每次迭代:O(N × M)
    N:种群大小
    M:解的维度(任务数×3)
  总迭代:T_max次
  FPA总复杂度:O(T_max × N × M)

TS部分:
  触发频率:T_max / N_ts次
  每次TS:O(|Neighborhood| × M)
  |Neighborhood| ≈ 20-50
  TS总复杂度:O((T_max/N_ts) × |N| × M)

总体时间复杂度:
O(T_max × N × M + (T_max/N_ts) × |Neighborhood| × M)
≈ O(T_max × N × M)  (因为N >> |Neighborhood|/N_ts)
```

- **空间复杂度** (1段+公式)
```
种群存储:O(N × M)
禁忌表:O(TabuTenure)
其他辅助空间:O(M)

总体空间复杂度:O(N × M + TabuTenure)
```
